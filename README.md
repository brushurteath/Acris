# Acris · 远航者

**把走过的路，留给后来的人。**

一个以“人人为我，我为人人”为理念的毕业生职业路径互助资料库。通过专业、学校层次和就读地区探索相近背景的职业去向，并在毕业后的 1、2、5、10 年持续更新。

## 当前可用功能

- 深空航道首页：母星夜面、启航城市、远航者微光和 1 / 2 / 5 / 10 光年坐标。以毕业年数映射叙事距离，航道亮度随当前记录数对数增长；支持降低动态效果的系统偏好。
- 一份职业档案对应一位远航者光点；真实空库不伪造人数，可手动切换明确标注的六条示例星图。夜空背景星点不代表用户。
- 响应式中文首页、专业 / 学校层次 / 地区筛选、关键词搜索和当前状态筛选。
- 职业路径详情、时间线和筛选样本状态分布。
- 邮箱密码注册登录、个人中心、本人资料导出与账号删除。
- 一人一份职业档案；提交后待审核，审核通过才公开。
- 管理员审核、退回意见；所有公开记录标为本人自述，审核不等于身份核验。
- 更正档案、追加回访、重新审核、立即撤回公开或删除资料。
- 毕业后 1、2、5、10 年的站内回访到期提醒与参与选择。
- 静态演示模式：没有 API 时显示明确标注的虚构案例，草稿只保存在浏览器。

当前免费。**没有支付、订单、提现、现金奖励、邮件验证、密码找回或自动发送回访邀请。** 示例不是调查数据。正式上线收集真实资料前，请完成部署、运营身份、隐私说明及所需资质的准备。

## 本地运行完整网站

安装 **Node.js 24 或更新版本**，无需安装第三方包。

```sh
git clone https://github.com/brushurteath/Acris.git
cd Acris
npm start
```

打开 <http://127.0.0.1:3000>。完整服务默认从空数据库开始，不会把虚构示例混入真实资料。

1. 在网页中注册自己的账号。
2. 在服务器终端授予这个**已经注册的账号**管理员权限：

   ```sh
   node server.mjs --grant-admin your@email.com
   ```

3. 刷新页面，进入“我的航程 → 审核工作台”。
4. 用普通账号提交档案，由管理员审核。通过后才会出现在公共查询页。

管理员权限只通过服务器命令授予，公开注册不会因为填写某个邮箱而得到管理员身份。回访目前在个人页面提醒，不会向任何人自动发送邮件或短信。

## 配置

复制 `.env.example` 为 `.env`，修改后使用：

```sh
node --env-file=.env server.mjs
```

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 监听地址，容器内使用 `0.0.0.0` |
| `PORT` | `3000` | 服务端口 |
| `APP_ORIGIN` | 当前请求的 HTTP Host | 外部完整来源，如 `https://example.com`，公开部署必须固定配置 |
| `COOKIE_SECURE` | `0` | HTTPS 部署设为 `1` |
| `DATA_DIR` | 项目内 `data/` | SQLite 数据目录，公开部署使用持久卷 |

数据库在 `data/acris.db`，相关 WAL 文件也属于运行数据。**永远不要把数据库、环境变量、备份、用户资料或密钥提交到 GitHub。** `.gitignore` 已排除常见运行数据；自行更改 `DATA_DIR` 时也要检查忽略规则。

## 两种部署方式

### A. 完整服务：支持账号与数据库

需要运行 Node.js 24 的服务器或容器，不能只上传到 GitHub Pages。提供了 `Dockerfile`、`compose.yaml` 和 `Caddyfile.example`，详见 [DEPLOYMENT.md](DEPLOYMENT.md)。SQLite 需要持久磁盘，当前架构适合单实例试运行。

### B. 静态演示：适合公开介绍项目

`dist/` 无需构建，可以交给静态托管平台或 GitHub Pages。仓库包含手动触发的 Pages 工作流，先在仓库 Settings → Pages 中选择 GitHub Actions，再运行 Deploy static demo。

**静态托管不包含 Node 服务。** 页面会标明演示模式，注册、审核和数据库功能不会假装可用。它只显示虚构案例，并允许在当前浏览器保存演示草稿。

Sites 的 `.openai/hosting.json` 保存当前预览站的身份，只用于该站维护。Fork 项目时不要复用其中的 `project_id` 创建自己的站点。

`Acris.com` 是项目期望域名，尚未注册、购买或绑定。本项目不声明拥有该域名。

## 数据与安全边界

密码使用随机盐与 scrypt 保存摘要；会话使用 HttpOnly、SameSite=Strict Cookie；写入请求校验来源和 CSRF Token；SQL 使用参数绑定；静态服务仅提供文件白名单。接口只把已审核记录的公开字段返回给访客。

本版不收集具体学校、公司名称、身份证、联系方式和证明文件。人工审核仍需留意自由文本中意外出现的可识别信息。组合信息也可能使熟人识别当事人，不能宣称完全匿名。

当前不提供独立的学历/雇佣核验、邮件验证、密码找回、分布式限流、灾备自动化、支付和奖励结算。限制与上线事项见 [DEPLOYMENT.md](DEPLOYMENT.md)。
